Amazon Sales Dashboard using Power BI

Project Overview

This project analyzes Amazon sales data using Power BI and generates insights related to sales performance and logistics to make better decisions for the company.


Dashboard Pages

1. Sales Overview Dashboard
2. Operations & Logistics Dashboard


Features

* KPI cards
* Sales Trend Analysis
* Product Category Performance
* Order Status Tracking
* Courier Status Analysis
* Fulfillment Analysis
* State-wise Sales Analysis
* Interactive Filters & Slicers


Tools Used

* Power BI
* Power Query
* DAX


Files Included

* Power BI Dashboard
* Project Report
* README


Key Insights

* T-shirts and shirts generated the highest revenue.
* Maharashtra and Karnataka were top-sales states.
* Amazon fulfillment handled the majority of orders.


Business Recommendations

* Improve logistics where cancellation rate is high.
* Focus on high demand categories and sizes.
* Expand marketing efforts in low-revenue states.
